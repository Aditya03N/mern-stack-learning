# MERN Stack Learning 🚀

## 📌 About This Repo
This repository is my personal learning journey with the **MERN stack** (MongoDB, Express, React, Node.js).  
I’m documenting what I practice each day, so this repo acts as both a codebase and a learning diary.

---

## 🖥️ What I Learned Today
- Built a **login form** in React.
- Used **react-hook-form** to manage inputs and validations.
- Added rules like required fields, min/max length, and displayed error messages.
- Connected the form to a backend server using **fetch API**.
- Set up an **Express server** with middleware (`cors`, `express.json`, `express.urlencoded`).
- Created simple **GET** and **POST** routes to handle requests.
- Successfully sent data from frontend to backend and logged it.

---

## 📝 Key Takeaways
- React Hook Form makes form handling and validation easier.
- Express middleware is essential for handling requests and enabling frontend-backend communication.
- Connecting frontend and backend helps understand how data flows in a full-stack app.
- This is the foundation of the **MERN stack workflow**.
