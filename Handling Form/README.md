# What I Learned Today 🚀

## 📌 Overview
Today I explored how to build a simple **login form** in React using form hooks and connected it to a backend server built with Express.  
This helped me understand both frontend form handling and backend request processing.

---

## 🖥️ Frontend (React)
- Learned how to use **react-hook-form** for managing form inputs.
- Added **validation rules** like required fields, minimum and maximum length.
- Displayed error messages when validation failed.
- Implemented a **loading state** while the form was submitting.
- Sent form data to the backend using **fetch API**.

---

## ⚙️ Backend (Express)
- Set up a basic **Express server**.
- Used **CORS middleware** to allow requests from the frontend.
- Learned how to parse **JSON** and **URL-encoded data**.
- Created simple **GET** and **POST** routes.
- Connected the frontend form submission to the backend and logged the received data.

---

## 📝 Key Takeaways
- ✅ How to use `react-hook-form` for easy form handling.
- ✅ How to validate inputs and show error messages.
- ✅ How to send data from React to Express using `fetch`.
- ✅ How to set up an Express server with middleware.
- ✅ How to handle GET and POST requests in Express.

---
